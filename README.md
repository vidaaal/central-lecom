# Central LECOM

Site estático de conhecimento para consulta de guias, processos, dúvidas e referências LECOM.

## Como abrir

Abra `index.html` em um navegador. O site é offline-first: inclui a fonte Inter localmente e não usa serviços externos.

## Recursos

- Busca de conteúdo (atalho `/`, limpar com `Esc`)
- Filtros por coleção e favoritos locais
- Alternância de tema salva neste navegador
- Links diretos para artigos e layout responsivo

Os favoritos e preferências são guardados apenas no navegador de cada pessoa; não são sincronizados.
